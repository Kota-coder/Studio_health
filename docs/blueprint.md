# **App Name**: CardioCapture

## Core Features:

- Image Capture & ID Selection: Capture patient images using the device camera and allow selection of ID card type from a dropdown menu.
- AI-Powered Data Extraction: Extract patient details from the captured ID card image using an AI-powered tool and populate corresponding input fields. 
- Image Management: Display the filename of the saved image and provide an option to delete the image if needed. The filename will follow the format: PatientFirstName_IDCardType.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for a calm and professional feel.
- Secondary color: White (#FFFFFF) for clean content sections.
- Accent: Teal (#008080) for interactive elements and highlights.
- Use a clean and organized layout with clear sections for image capture, data display, and manual input fields.
- Employ recognizable icons for actions like 'Capture,' 'Delete,' and 'Save.'
- Use subtle transitions and animations for a smooth user experience when capturing and processing images.

## Original User Request:
Create an to intake cardio patients information with following features :

Capture an image using the device camera.
Select the identity card type from a dropdown (options include Aadhar Card, Driver's License, PAN Card, etc.).
Extract patient details from the captured image using AI.
Manually input and edit patient details like name, date of birth, address, emergency contact, 
Save the captured image with a filename that follows the format: PatientFirstName_IDCardType.
View the name of the file that is saved in the applicatin and show the option to delete if needed
